# Focus Pet 设计文档

> 版本：v0.2（2026-08-14 头脑风暴定稿，v1 骨架落地）
> 定位：一款"陪你学习、也监督你学习"的桌面养成宠物。

## 一句话定位

平时卖萌，你摸鱼时通过**情绪温度计**逐级变生气，并用动画 + 阻断机制管住你；
摄像头看脸也看手，电脑前学习、纸上写字看书都算学习。

## 核心闭环

摄像头盯人（在不在 / 看没看屏幕 / 手在干嘛）→ 屏幕监控（活动窗口 / 进程 / 标签页）
→ 判定引擎（黑名单 + 白名单特例）→ 宠物表现（情绪温度计）→ 阻断执行（分级）。

## 一、核心监督（感知层）

1. **摄像头监督（v2）**：人脸 + 视线 + 手部识别，四种状态：
   - 屏幕学习：人脸在 + 看屏幕
   - 离屏学习：低头 + 手在桌面区域活动（写字 / 翻书 / 持笔）→ 也算专注
   - 疑似玩手机：低头 + 手持物体贴近面部 / 手指滑动 → 进入怀疑流程
   - 离开：人脸不在
2. **屏幕监督（v1 已实现窗口部分）**：
   - 快速通道：活动窗口标题 + 进程名（+ v1.5 浏览器扩展回填标签页 URL）
   - 慢速通道（v2.5 已实现）：快速通道判定不了时才触发**本地截图分析**（`sensors/screen_analyzer.py`），不保存不上传
3. **浏览器扩展（v1.5 已实现）**：`browser_extension/`，URL 级检测，监听 URL 变化；黑名单命中即跳转拦截页，白名单特例/教宠物放行；经本地桥接服务（`bridge/`）与主程序通信，数据不出本机。

## 二、判定规则

1. **黑名单为主**：游戏、抖音等明确分心内容（`data/blacklist.json`）
2. **白名单特例**：黑名单基础上放行具体链接/应用（`data/whitelist.json`），支持子串/前缀匹配
3. **优先级**：白名单特例 / 教宠物 > 黑名单 > 学习关键词 > 工具进程 > unknown
4. **三类结果**：study（计专注）/ tool（放行不计专注）/ distraction（阻断）/ unknown（保守放行）
5. **教宠物**：误判时右键"这个是学习用的！"，宠物记住（`data/learned.json`）
6. **声明制**：开始前告诉宠物"我要学 XX"，结束时给出总结（`data/focus_log.json`）

## 三、情绪系统（人设：严师 + 萌宠一体）

- 不是瞬间变脸，而是**情绪温度计**：分心越久越生气，回到学习后**逐渐消气**
- 阻断级别由连续分心时长触发（默认：5 秒→Lv1 / 15 秒→Lv2 / 30 秒→Lv3 / 60 秒→Lv4，可配置）
- 情绪值未来直接接入养成系统（好感度）

## 四、阻断系统（分级）

| 级别 | 行为 | 宠物表现 |
|---|---|---|
| Lv1 | 提醒 | 皱眉 + 气泡"该学习啦" |
| Lv2 | 动画遮挡 | 放大挡在屏幕中间 |
| Lv3 | 最小化 | 明显生气、红脸、把窗口收起来 |
| Lv4 | 强制关闭 | 暴怒 + 倒计时警告后发送 WM_CLOSE |

- **强制关闭只对高置信度非学习内容**生效；文档类永不强制关
- **浏览器标签页由扩展拦截**（跳转拦截页）；桌宠对浏览器窗口只提醒、不最小化/关闭
- 强制关闭**默认关闭**，需在 `data/config.json` 手动开启，带保存倒计时
- **承诺锁**：退出桌宠需输入退出码（默认关，`data/config.json` 开启），记录"逃跑"次数（v3 与养成挂钩）

## 五、番茄钟（开关）

- 开：专注/休息循环（默认 25/5），休息窗口解除限制，宠物切萌宠催你休息
- 关：持续监督模式

## 六、隐私设计

1. 摄像头：本地实时推理，**不保存、不上传**
2. 截图分析：本地识别，**不保存、不上传**
3. 屏幕监控默认只读窗口标题/进程名，**不全程截图**

## 七、桌宠形象系统

- **用户传图个性化**：用户提供图片生成专属桌宠（`tools/make_skin.py` 自动抠图/去底）
- **皮肤系统（v3.5 升级为主题资源包）**：`skins/<名字>/` 目录 = 一个主题，可含
  `theme.json` 清单 + 每状态一张图（happy/curious/annoyed/angry/furious/celebrate/error/sleep/idle）；
  回退链：指定状态图 -> idle.png -> pet.png -> 程序化小猫；旧版单图皮肤完全兼容
- **工具链**：`tools/theme_scaffold.py` 一张图生成主题骨架；`tools/validate_theme.py` 校验缺图；
  右键「导入主题包…」/ `--import-theme` 导入 zip
- 分阶段：
  - v1.5 方案 A：图片皮肤（自动缩放 + 白底去除 / rembg 抠图工具）
  - 进阶方案 B：图像模型生成 Q 版/贴纸风（一次性生成，需联网 + 用户同意）
  - 远期方案 C：Live2D 动态立绘

### 自定义图像适配原则（硬性约束，所有版本必须遵守）

> 用户的"自定义图像桌宠"是一等公民：任何新功能都必须对自定义图像可用，不能只服务于程序化小猫。

1. **一张图 = 一个可用桌宠**：用户只有一张图时，自动回退到所有状态（回退链：指定状态图
   -> idle.png -> pet.png -> 程序化小猫），再叠加表情标记（皱眉/腮红/汗滴）。
2. **多状态可升级**：用户想更生动，可单独放 angry.png / furious.png / celebrate.png /
   error.png / sleep.png，逻辑不用改（换图不换脑）。
3. **表情/装饰品定位依赖人脸元数据**（pet.json，导入时自动检测）；检测不到时居中兜底，
   绝不能崩溃。
4. **托盘图标跟随当前皮肤**：换皮肤后托盘小猫头一起变；无 PIL 时回退默认橙猫。
5. **特效必须画在形象外部**：庆祝星光/出错感叹号/睡觉Zzz/阴影是"形象无关"的层，
   对自定义图同样生效。
6. **远期 Live2D 也要保留回退路径**：没有骨骼模型时，自定义图仍按"单图 + 表情叠加"工作。
7. **新增任何 UI 元素/动画前**，先在脑子里过一遍："我的自定义图在这个功能下长什么样？"
   答不上来就先做通用方案。

## 八、四大扩展功能（路线图中）

1. **养成**：专注时长积累 → 宠物进化 / 换装
2. **"你在看我吗"**：宠物发现你看它而不是屏幕，歪头盯着你
3. **分心日志**：每天时间线（`data/events.json`，v1 已记录分心事件）
4. **多档模式**：考试冲刺 vs 日常自习

## 九、技术架构

- **Python 后端 + Tkinter 渲染**（v1，纯标准库，零第三方依赖）
- 后续可平滑升级渲染层为 HTML/CSS/JS（pywebview / Electron），感知层换 MediaPipe
- 模块分层：

```
focus-pet/
├── main.py              # 入口：监督循环 + CLI
├── core/                # 配置 / 规则 / 情绪 / 会话 / 番茄钟 / 日志（与界面无关）
├── sensors/             # 感知层：window_monitor（v1）；camera（v2）
├── ui/                  # 桌宠窗口：pet_app.py（渲染 + 皮肤）
├── blockers/            # 阻断执行：提醒 / 遮挡 / 最小化 / 强制关闭
├── bridge/              # 本地桥接服务（浏览器扩展 <-> 主程序）
├── browser_extension/   # Chrome/Edge 扩展（MV3）：URL 拦截 + 教宠物
├── tools/               # 辅助工具（make_skin.py 皮肤制作）
├── data/                # config / blacklist / whitelist / learned / 日志
├── docs/                # 设计文档
└── skins/               # 皮肤资源包
```

- 升级 = 增量修改（在对应模块加文件），不推倒重来

## 十、路线图

- **v1（已完成）**：桌宠（程序化形象）+ 情绪温度计 + 黑名单/特例 + 番茄钟开关 + 窗口/进程检测 + 提醒/遮挡/最小化 + 分心日志 + 声明制
- **v1.5（已完成）**：浏览器扩展（URL 级黑名单/特例 + 教宠物 + 拦截页）+ 图片皮肤（自动缩放 + `make_skin.py` 抠图工具）+ 本地桥接服务
- **v2（摄像头部分已完成）**：摄像头（人脸 + 视线 + 手部识别：离屏学习/玩手机判定，MediaPipe Tasks API）
- **v2 附：摄像头设置窗口**（`--camera-setup`：图形界面选前置/后置、实时预览、人脸检测推荐）
- **v2.5（已完成）**：截图画面分析（OCR 文字 + 图案/结构 + 颜色 + 可训练分类器，本地识别，tools/ 提供数据采集与训练管道）
- **v3（已完成）**：养成进化（等级/皇冠/金边）+ 好感度 + 多档模式（日常/考试冲刺）+ 用户自定义桌宠（右键更换/导入）
- **v3.1（已完成）**：专注币商店（装饰品/家具）+ 个人空间 + 自定义形象自动适配（人脸检测元数据）
- **v3.5（已完成）**：事件→状态→动画状态机 + 主题资源包（theme.json / 每状态一张图 / 脚手架 / 校验 / zip 导入）
  + 分级动画（angry/furious 分级）+ 完成庆祝/出错反馈/睡觉动画 + 系统托盘 + 单实例锁 + 位置记忆 + 轻量 UI 美化
- **v3.6**：UI 全面现代化 + 音效 + 免打扰 DND + 迷你模式 + 全局快捷键
- **形象生成进阶**：Q 版/Live2D（远期）
- **打包分发**：PyInstaller exe + 图形化设置界面 + 扩展上架应用商店

## 十一、v1 已知限制（诚实清单）

1. UI 界面较简陋（设置窗口/桌宠外观），全面美化排在 v3
2. 强制关闭默认关闭
3. 摄像头依赖：opencv-python + mediapipe，模型在 models/（首次用 tools/fetch_models.py 下载）
4. 浏览器标签页拦截依赖扩展：需在 Chrome/Edge 手动加载，且 Focus Pet 运行时才生效
5. 没有 git 环境时需先装 git 再 `git init`

### 想法 2：开发者编辑器（集中配置中心）—— ✅ 已实现（V3.3）
- 目标：所有可调参数集中在一处，改一个值全项目生效（含代码）
- 示例：专注币汇率（当前 1 分钟 1 币 → 想改成 10 分钟 1 币）、阻断阈值、
  等级经验表、商品价格、关键词列表
- 形式：图形化设置窗口；代码所有地方只读这一处配置
- 设计要点：
  1. 把散落在代码里的"魔法数字"全部收敛到集中配置（金币汇率/价格/阈值/经验表/关键词）
  2. GUI 编辑器改值即改即生效（沿用现有配置热更新机制）
  3. 支持"导出/导入配置"，方便备份与分享
