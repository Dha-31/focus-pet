## 一、本次目标

1. 按第六次总结的结论，把 HTML 桌宠落到 **Electron**（pywebview/CEF 已判不可行），实现真透明。
2. **正式集成**：`main.py` 优先 Electron，失败回退 Tk；全功能接通。
3. 修复体验问题：退出关不掉、右键菜单显示不全、黑色控制台。
4. 按用户要求**删除**打工、摄像头监督两个功能。
5. 加**开发者模式守卫**：打包成客户端时自动隐藏集中配置编辑器等开发者功能。

## 二、已完成内容

### 1. Electron HTML 桌宠落地（核心）
- 下载 **Electron 43.2.0** 运行时（137MB，`tools/electron/runtime`，不提交 git）。
- 新增 `desktop/` 壳：`main.js` + `preload.js` + `package.json`。
  - 透明 + 无边框 + 置顶 + `hasShadow:false` + `backgroundColor:#00000000`。
  - **`app.disableHardwareAcceleration()`**：无独显机器上透明可靠的关键（解决黑屏）。
  - **鼠标穿透**（`setIgnoreMouseEvents`，学 Open-LLM-VTuber）：平时不挡桌面，鼠标移到猫身上才可交互。
  - **系统托盘**：点"退出"=最小化到托盘；托盘右键"退出"=真正关闭；单击托盘图标显示/隐藏。
  - 本地 HTTP 轮询 Python 状态（outbox）+ 接收前端命令（command）。
- `ui/web_pet/index.html`：黄猫 SVG（呼吸/眨眼/情绪/抖动）+ 气泡（脑袋右侧、字号≤12、不两字换行、限高滚动菜单）+ 鼠标穿透 + 拖拽 + 状态接收。
- `ui/web_pet/pet_electron.py`：`ElectronPetWindow`（HTTP 通信 + **PetApp 兼容层**：辅助窗口/对话框/空间商店/属性）。
- **`main.py` 集成**：优先 `ElectronPetWindow`，失败/缺运行时回退 `PetApp`（Tk）；托盘按渲染器分支。

### 2. 体验问题修复
- 气泡：紧贴脑袋右侧（gap≈13px）、字号固定 12px（迷你 9px）、每行≥4 字不两字换行、窗口加宽。
- **退出关不掉**：菜单打开时强制可交互（不再穿透）→ 能点"退出"；前端"退出"=最小化到托盘（不真正退出）。
- **右键菜单显示不全**：20 项高度超窗口 → 限高 + 滚动，全部可访问。
- **菜单重分类**：学习 / 养成 / 空间与商店 / 学习数据 / 系统 / 帮助与退出（打工已删）。
- **黑色控制台**：打包脚本加 `--windowed`（最终用户版无控制台）；开发版保留便于反馈。
- **开机自启**：`core/autostart.py`（注册表 HKCU Run），右键菜单"系统 → 开机自启"开关。

### 3. 功能删除
- **打工（工作时钟）**：main.py / pet_app.py / settings_schema / help_data / `core/work.py` 全删。
- **摄像头监督**：`camera/`、`ui/camera_setup.py`、`camera_check.bat`、main.py 摄像头逻辑、
  config / settings_schema / help_data / help_window / requirements / build_exe 全删（保留屏幕分析）。

### 4. 开发者模式守卫
- 新增 `core/dev.py`：`is_dev_mode()` = `not sys.frozen`（源码运行=True，打包 exe=False）。
- 三个入口守卫：
  1. 帮助中心"关于"页"开发者"条目（用户版隐藏）。
  2. 集中配置编辑器"开发者参数"页（用户版只显示"应用配置"）。
  3. `--settings` 命令行（用户版提示不可用）。
