# Focus Pet 项目总结

> 更新时间：2026-08-14（V3.1 完成）

## 一、项目定位

一款"陪你学习、也监督你学习"的桌面养成宠物：平时卖萌，摸鱼时通过情绪温度计逐级变生气，
用动画 + 阻断机制管住你；摄像头看脸也看手，电脑前学习和纸上写字看书都算学习；
专注攒经验升级、赚专注币，装扮宠物、布置个人空间。

## 二、已完成功能（按版本）

### v1 — 桌宠本体
- 透明置顶小窗、程序化小猫（浮动/眨眼/表情：开心→好奇→不耐烦→生气→暴怒）
- **情绪温度计**：分心越久越生气，回到学习慢慢消气
- **活动窗口检测**：前台窗口标题 + 进程名（ctypes，不截图不保存）
- **判定规则**：黑名单为主 + 白名单特例 + "教宠物"（热更新，改配置 1 秒生效）
- **分级阻断**：提醒 → 动画遮挡 → 最小化 → 强制关闭（带保存倒计时，默认关）
- 番茄钟开关、声明制会话、分心日志、退出承诺锁

### v1.5 — 浏览器拦截 + 皮肤
- Chrome/Edge 扩展（MV3）：URL 级黑名单/白名单特例/教宠物，拦截页
- 本地桥接服务（127.0.0.1，数据不出本机）
- 图片皮肤系统 + 一键抠图工具

### v2 — 摄像头监督
- MediaPipe 人脸 + 手部识别（Tasks API，本地处理不保存不上传）
- 离屏学习（纸上写字/看书 = 专注）、疑似玩手机、人不在 三种状态
- **摄像头设置窗口**（图形界面选前置/后置、实时预览、人脸检测推荐）

### v2.5 — 截图画面分析
- 多信号融合：OCR 文字（离线中文）+ 图案/结构（视频播放器/代码编辑器/文档排版）+ 颜色 + 可训练分类器
- 训练管道：合成数据 + 真实数据采集 + 自动清洗 + 训练（tools/）
- 快速通道判定不了时才触发，本地处理

### v3 — 养成系统
- **等级进化**：专注攒经验，Lv.4 戴皇冠、Lv.6 金色描边、越长越大
- **好感度**：学习 +、摸鱼 −（0-100）
- **多档模式**：日常自习（宽松）/ 考试冲刺（严格）
- **用户自定义桌宠**：右键"更换形象"切换/导入自己的图片

### v3.1 — 商店 + 个人空间 + 形象适配
- **专注币**：专注 1 分钟 = 1 币
- **商店**：装饰品（帽子/蝴蝶结/眼镜/围巾/小花/皇冠）+ 家具（地毯/台灯/绿植/窗户/学习桌/书架/沙发）
- **个人空间**：宠物房间，摆放家具（最多 6 件），宠物入住
- **自定义形象自动适配**：导入时识别人脸位置，装饰品戴在脸上、表情标记贴到脸上

## 三、技术架构

```
focus-pet/
├── main.py            # 入口：监督循环 + CLI（--headless-check / --camera-check / --screen-check / --status / --log）
├── core/              # 配置 / 规则 / 情绪 / 会话 / 番茄钟 / 日志 / 养成 / 经济 / 商品
├── sensors/           # 窗口检测 / 截图分析
├── camera/            # 摄像头（MediaPipe + OpenCV 降级）
├── ui/                # 桌宠窗口 / 绘制渲染 / 商店 / 个人空间 / 摄像头设置 / 人脸元数据
├── blockers/          # 分级阻断
├── bridge/            # 本地桥接服务（浏览器扩展 <-> 主程序）
├── browser_extension/ # Chrome/Edge 扩展
├── tools/             # 抠图 / 模型下载 / 数据采集 / 清洗 / 训练 / 皮肤制作
├── data/              # 配置与用户数据（运行时生成）
├── models/            # AI 模型（.task + 训练好的分类器）
└── docs/              # 设计文档 / 项目总结
```

- 基础功能纯 Python 标准库；可选增强：opencv / mediapipe / rapidocr / scikit-learn
- 升级方式 = 增量修改（在对应模块加文件），git 版本管理（9 次提交）

## 四、隐私承诺

摄像头画面、截图、窗口信息**全部本地处理，不保存、不上传**；浏览器扩展只连 127.0.0.1 本地桥接。

## 五、未来目标

- **v3.5 UI 全面美化**：桌宠界面、商店、个人空间、摄像头设置全部现代化（用户反馈当前界面老旧）
- **打包分发**：PyInstaller 打包成 exe + 图形化设置界面 + 扩展上架应用商店 + 发布到 GitHub
- **形象生成进阶**：Q 版/贴纸风格生成；Live2D 骨骼绑定（让自定义照片真正变表情）
- **防绕过强化**：承诺锁/逃跑机制与养成（好感度/金币）深度挂钩
- **成就与统计**：学习成就系统、专注数据报表

## 六、新想法记录（待实现）

### 想法 1：学习 GitHub 上其他桌宠项目
- 调研他人已完成的桌宠项目（GitHub），借鉴：产品功能、交互设计、技术架构、动画实现
- 输出：功能对照表 + 可吸收的改进点清单

### 想法 2：开发者编辑器（集中配置中心）
- 目标：所有可调参数集中在一处，改一个值全项目生效
- 示例：专注币汇率（现在 1 分钟 1 币 → 想改成 10 分钟 1 币）、阻断阈值、等级经验表、
  商品价格、关键词列表等
- 形式：图形化设置窗口（或集中配置文件），代码所有地方只读这一处配置
- 设计要点：
  1. 把散落在代码里的"魔法数字"全部收敛到集中配置（金币汇率、价格、阈值、经验表）
  2. 提供 GUI 编辑器：改汇率/价格/阈值即改即生效（热更新）
  3. 可选"导出/导入配置"，方便备份与分享
