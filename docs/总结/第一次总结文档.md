## 一、本次里程碑

## 二、已完成功能

### v1 — 桌宠本体
- 透明置顶小窗、程序化小猫（浮动/眨眼/表情：开心→好奇→不耐烦→生气→暴怒）
- 情绪温度计：分心越久越生气，回到学习慢慢消气
- 活动窗口检测：前台窗口标题 + 进程名（ctypes，不截图不保存）
- 判定规则：黑名单为主 + 白名单特例 + "教宠物"（热更新）
- 分级阻断：提醒 → 动画遮挡 → 最小化 → 强制关闭（带保存倒计时，默认关）
- 番茄钟开关、声明制会话、分心日志、退出承诺锁

### v1.5 — 浏览器拦截 + 皮肤
- Chrome/Edge 扩展（MV3）：URL 级黑名单/白名单特例/教宠物，拦截页
- 本地桥接服务（127.0.0.1，数据不出本机）
- 图片皮肤系统 + 一键抠图工具

### v2 — 摄像头监督
- MediaPipe 人脸 + 手部识别（本地处理不保存不上传）
- 离屏学习 / 疑似玩手机 / 人不在 三种状态
- 摄像头设置窗口（图形界面选前置/后置、实时预览、人脸检测推荐）

### v2.5 — 截图画面分析
- 多信号融合：OCR 文字 + 图案/结构 + 颜色 + 可训练分类器
- 训练管道：合成数据 + 真实数据采集 + 自动清洗 + 训练
- 快速通道判定不了时才触发，本地处理

### v3 — 养成系统
- 等级进化：Lv.4 戴皇冠、Lv.6 金色描边、越长越大
- 好感度：学习 +、摸鱼 −（0-100）
- 多档模式：日常自习 / 考试冲刺
- 用户自定义桌宠：右键"更换形象"切换/导入图片

### v3.1 — 商店 + 个人空间 + 形象适配
- 专注币：专注 1 分钟 = 1 币
- 商店：装饰品 6 种 + 家具 7 种
- 个人空间：宠物房间 + 摆放家具（最多 6 件）
- 自定义形象自动适配：导入时识别人脸，装饰品/表情贴到脸上

## 三、技术架构

```
focus-pet/
├── main.py            # 入口：监督循环 + CLI
├── core/              # 配置 / 规则 / 情绪 / 会话 / 番茄钟 / 日志 / 养成 / 经济 / 商品
├── sensors/           # 窗口检测 / 截图分析
├── camera/            # 摄像头（MediaPipe + OpenCV 降级）
├── ui/                # 桌宠窗口 / 绘制渲染 / 商店 / 个人空间 / 摄像头设置 / 人脸元数据
├── blockers/          # 分级阻断
├── bridge/            # 本地桥接服务
├── browser_extension/ # Chrome/Edge 扩展
├── tools/             # 抠图 / 模型下载 / 数据采集 / 清洗 / 训练
├── data/              # 配置与用户数据
├── models/            # AI 模型
└── docs/              # 设计文档 / 总结日志
```

- 基础功能纯 Python 标准库；可选增强：opencv / mediapipe / rapidocr / scikit-learn
- 升级方式 = 增量修改；git 版本管理

## 四、隐私承诺

摄像头画面、截图、窗口信息全部本地处理，不保存、不上传；浏览器扩展只连 127.0.0.1 本地桥接。
