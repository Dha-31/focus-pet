## 三、隐私政策（复制到你的官网/仓库页，商店要求提供）

> **Focus Pet Bridge 隐私说明**
> 本扩展仅在你本机的 Focus Pet 桌面程序运行时工作，用于"专注监督"。
> 1. 收集内容：当前活动标签页的 URL 和标题。
> 2. 用途：仅发送到本机 127.0.0.1 的 Focus Pet 本地服务，用于判定该页面是"学习"还是"分心"并拦截黑名单网站。
> 3. 不收集：不收集任何个人信息，不上传任何数据到服务器，无广告、无统计、无追踪。
> 4. 存储：所有判定与日志均保存在你自己的电脑上（data/ 目录），可随时删除。
> 5. 联系方式：（填入你的邮箱）

## 四、Edge 上架步骤

1. 打开 https://microsoftedge.microsoft.com/addons/ 用微软账号登录，进入开发者后台
2. 点"创建新扩展"，上传 `browser_extension.zip`
3. 填写：名称 / 简介 / 详细描述 / 隐私政策链接 / 分类（Productivity）
4. 上传商店图标（128x128）和 1-5 张截图
5. 提交审核（通常 1-7 天）

## 五、Chrome 上架步骤

1. 注册开发者：https://chrome.google.com/webstore/devconsole （需 $5 一次性注册费）
2. 开发者后台 → 上传新项目 → 选择 `browser_extension.zip`
3. 填写商店信息 + 隐私政策 + 截图
4. 提交审核（通常 1-3 天，可能要求补充权限说明）

## 六、常见被拒原因

- 权限过多：我们只用 `tabs` + 本机 host_permissions，如果审核问起，解释"用于读取当前标签页以便本地监督"
- 缺少隐私政策：务必提供上面那份文案的公开链接
- 说明不清：描述里写清楚"本地专注监督工具，数据不出本机"

## 七、重新打包

改完代码后重新打包：
```powershell
cd 项目根目录
Compress-Archive -Path browser_extension -DestinationPath browser_extension.zip -Force
```
## 八、上架后如何更新（重要）

Edge / Chrome 扩展上架后**可以持续更新**，而且用户浏览器会**自动升级**，不用重新手动加载。

更新流程：
1. 改版本号：编辑 `browser_extension/manifest.json` 的 `version`（必须比上一版大，如 0.2.0 -> 0.2.1）
2. 改完代码后重新打包：
   ```powershell
   cd 项目根目录
   Compress-Archive -Path browser_extension -DestinationPath release/browser_extension.zip -Force
   ```
3. 登录 Edge 合作伙伴中心（Partner Center）-> 找到已发布的扩展 -> 提交新版本
4. 上传新 zip + 填写本次更新说明（如"修复 XXX / 新增 XXX"）
5. 提交审核（通常 1-7 天），审核通过后自动向所有用户推送更新

注意：
- 版本号只能递增，不能重复或降级
- 更新后用户浏览器通常几小时到几天内自动升级，用户无需操作
- 已安装用户的数据会保留（URL 上报逻辑升级时，桌宠和扩展需保持协议兼容）
- 如果只改桌宠（不涉及扩展协议），扩展不用更新；只有改 `browser_extension/` 里的代码才需要发新版
