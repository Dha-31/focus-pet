## 二、第 1 名：BongoCat（ayangweb/BongoCat）

**一句话**：目前全 GitHub 最火的桌宠，一只会用爪子打鼓/跟随你键盘鼠标动作的 Live2D 猫，支持 Windows / macOS / Linux(x11)。

- 源码位置：`research/BongoCat`
- 技术栈：前端 Vue 3 + Vite + UnoCSS，桌面壳 Tauri（Rust），模型是 **Live2D Cubism 3**（.moc3 / .model3.json / .exp3.json）
- 许可证：MIT（可自由使用/修改，保留版权声明即可）
- 下载安装：GitHub Releases 有 Windows/macOS/Linux 安装包；还有夸克网盘渠道
- 社区生态：Awesome-BongoCat（1895⭐）收集第三方猫咪模型；有在线模型转换工具

**核心功能**：
- 根据键盘、鼠标、手柄输入实时同步动作（打鼓、敲键盘等）
- 支持导入自定义 Live2D 模型（从 Bongo-Cat-Mver 格式在线转换）
- 完全本地离线运行，不收集任何用户数据
- 设置面板：模型选择、快捷键、开机自启、多语言（中/英/葡/越/繁中）

**起源**：灵感来自 MMmmmoko/Bongo-Cat-Mver（C++，1103⭐，仅 Windows），BongoCat 用 Tauri 做成跨平台。

**对 Focus Pet 的借鉴点**：
1. **Live2D 模型格式 + 模型导入**——用户自定义桌宠这条线可以学它：定义一套标准模型格式 + 转换工具 + 模型市场
2. **输入事件→动作同步**——把"键盘/鼠标事件"映射成动画，和咱们"分心事件→动画"是同一套思想
3. **Tauri 打包分发**——比 Electron 小得多（10MB 级 vs 100MB+），以后如果要给用户发客户端，Tauri/Rust 是省体积的好选择

## 三、第 2 名：VPet 虚拟桌宠模拟器（LorisYounger/VPet）

**一句话**：国产开源桌宠"模拟器"，一个可嵌入任何 WPF 程序的桌宠框架，免费上架 Steam，带创意工坊（MOD 生态）。

- 源码位置：`research/VPet`（源码 1.4GB，主要是动画素材）
- 技术栈：C# / WPF / .NET，核心库 VPet-Simulator.Core 可通过 NuGet 内嵌到任何 WPF 应用
- 许可证：Apache-2.0（宽松，可商用，需保留声明）；注意自带动画版权归"虚拟主播模拟器制作组"，使用有附加条款
- 下载：Steam 免费（1920960），或 NuGet 当库用

**核心功能**：
- 动画：32 种类型 × 4 种状态 × 3 种类型 的动画组合（摸头、提起、爬墙、投喂等）
- 互动：点它、摸头、喂食、提起拖拽、爬墙、工作时钟
- 创意工坊（Steam Workshop）：玩家可上传/下载
  - 桌宠动画
  - 物品/食物/饮料
  - 自定义"桌宠工作"（让宠物去"上班"）
  - 说话文本、主题
  - **代码插件**：通过写代码给桌宠加新动画方案（L2D/spine）、新功能（闹钟/记事板）
- 附带工具：MOD 制作器（帧图生成）、开发者控制台、反馈中心、ChatGPT 设置窗口

**架构亮点**：
- `VPet-Simulator.Core`：可嵌入核心（图形渲染/动画/存档/食物接口/宠物加载器）
- `VPet-Simulator.Windows`：桌面端壳（窗体/UI/设置/MOD 管理）
- `VPet-Simulator.Tool`：MOD 制作工具
- 插件示例：VPet.Plugin.Demo

**对 Focus Pet 的借鉴点**：
1. **"可嵌入核心 + 壳"的分层架构**——咱们可以把监督逻辑做成 core，UI 随时换壳
2. **创意工坊/MOD 生态**——和咱们"开发者编辑器+以后可扩展"的思路一致，且它验证了"用户自制内容"能极大提升生命力
3. **代码插件系统**——新功能不用改主程序，以插件形式加载，正好对应你说的"以后加新功能不用重装"
4. **动画版权声明**——提醒咱们：用网上动画素材要查清楚版权，避免商业风险

## 四、第 3 名：clawd-on-desk（rullerzhou-afk/clawd-on-desk）

**一句话**：一只像素小螃蟹，实时盯着你的 AI 编程助手（Claude Code / Codex / Cursor 等）在干嘛，然后做出反应——和咱们"监督你在干嘛"的定位最像！

- 源码位置：`research/clawd-on-desk`
- 技术栈：Electron + Node.js/TypeScript，动画是 SVG/GIF/APNG/WebP
- 许可证：AGPL-3.0（强 copyleft：借用了代码，你的项目也得开源）
- 下载：GitHub Releases 提供 Windows(x64/arm64)/macOS/Linux 安装包；需 Node.js 才能跑源码
- 支持平台：Windows 11 / macOS / Linux；更新极快（2026-03 创建，几个月 5.9k⭐）

**核心功能**：
- 实时监听 20+ 个 AI 编程助手的生命周期事件（hook 机制），把事件映射成宠物状态动画：
  - 思考中（气泡）、打字工作、构建中、多子代理=玩杂耍、出错=难过、完成=庆祝、60 秒鼠标空闲=睡觉
- **权限气泡**：AI 要请求权限时，宠物弹出气泡让你批准/拒绝（有拦截功能）
- 三套内置主题：Clawd（螃蟹）、Calico（三花猫）、Cloudling（云宝）；**支持自定义主题**：
  - 可导入 Codex Pet 动画包 zip；`theme.json` 描述，最少 1 张 SVG 待机 + 7 张状态图即可
  - 有主题脚手架脚本和校验脚本
- 系统级能力：点击穿透、记忆位置、单实例锁、开机自启、免打扰(DND)、音效、系统托盘、6 种语言、自动更新、多显示器适配、迷你模式
- 附加：远程 SSH hook 部署、PWA 手机端伴侣（手机批准权限）

**架构亮点**：
- **事件→状态→动画** 三层映射表（docs/guides/state-mapping.md 有完整表格）——这是它最值得学的设计
- 主题系统 = 一套标准状态名 + 每状态一张图，换皮肤=换图，逻辑完全不动

**对 Focus Pet 的借鉴点**：
1. **事件→状态→动画 映射表**：把"分心/学习/番茄钟/摄像头状态"定义成一组状态，再给每个状态配动画。以后换皮肤只换图，不用改逻辑——这和咱们自定义桌宠的需求完全吻合
2. **主题脚手架 + 校验脚本**：用户给一张图，脚本自动生成"待机/生气/开心/睡觉"等状态模板，用户填图即可——可以直接抄这个产品设计
3. **权限气泡/拦截动画**：和咱们"阻止打开分心网站"的强制关闭动画同思路，可以看看它怎么做得不招人烦
4. **多显示器/点击穿透/位置记忆**：这些都是桌宠体验细节，咱们后期要补

## 五、补充：RunCat365（runcat-dev/RunCat365）

**一句话**：任务栏里一只小猫，你的 CPU 占用越高它跑得越快，微软商店免费下载。

- 源码位置：`research/RunCat365`
- 技术栈：C# / Win32 / .NET 9.0，微软商店分发
- 许可证：Apache-2.0
- 为什么 Star 高：简单、可爱、零学习成本、无侵入（不挡桌面）
- 额外功能：自定义跑步动画、内置一个跑酷小游戏、8 种语言

**对 Focus Pet 的借鉴点**：它证明了"用一个系统指标做宠物动画驱动"的玩法（CPU→速度）。咱们可借鉴：把"专注时长/分心次数"变成宠物的某种持续动画（比如专注时打盹、分心时踱步）。

## 六、对我们的启示（总结）

1. **前三名三套技术路线**：
   - BongoCat = 现代 Web 技术 + 轻量壳（Vue + Tauri），界面精致、模型生态强
   - VPet = 传统桌面技术（C#/WPF），架构可嵌入、MOD 生态强
   - clawd-on-desk = Electron + 像素动画，事件驱动设计最先进、和"监督"最相关
2. **Focus Pet 应该借鉴的组合拳**：
   - 借鉴 clawd-on-desk 的「事件→状态→动画」映射表和主题脚手架（换皮不换脑）
   - 借鉴 BongoCat 的模型导入/模型市场思路（用户自定义桌宠）
   - 借鉴 VPet 的插件化架构（以后加功能不用重装、编辑器改一处全生效）
   - 借鉴 RunCat365 的"系统指标驱动动画"小玩法
3. **许可证提醒**：MIT / Apache-2.0 可以放心参考；AGPL-3.0 的项目（clawd-on-desk）只能借鉴"设计思路"，不能直接抄代码，否则咱们也得开源。
4. **经典项目已下架**：DesktopGoose / Shimeji-ee / DesktopPet 官方源码已从 GitHub 删除，要学只能找 fork。

## 七、功能差距分析（Focus Pet 目前没有的，按项目整理）

> 对比基准：Focus Pet v3.3 已实现功能（桌宠/情绪温度计/黑名单白名单/分级阻断/番茄钟/浏览器扩展/图片皮肤/摄像头/截图分析/养成/商店/个人空间/成就/报表/你在看我吗/四档模式/防绕过/开发者编辑器）

### A. BongoCat 有、咱们没有的
1. **Live2D 动态模型**：猫是实时动态立绘（表情/动作持续变化），咱们是静态图片皮肤
2. **输入事件→动作同步**：键盘/鼠标/手柄驱动宠物动作（打鼓、敲击），咱们不响应输入行为
3. **模型导入 + 在线转换工具 + 模型市场**：Awesome-BongoCat（1895⭐）社区模型库，咱们只有单张图片皮肤，没有标准模型格式/市场
4. **全局快捷键**（源码确认 @tauri-apps/plugin-global-shortcut）：咱们没有
5. **托盘图标**（源码确认 useTray.ts）：咱们只有宠物右键菜单，没有托盘
6. **开机自启能力**：咱们没有
7. **多语言 i18n**（中/英/葡/越/繁中）：咱们纯中文
8. **轻量打包**：Tauri 10MB 级，咱们规划 PyInstaller exe（100MB 级）
9. **手柄输入**（useGamepad.ts）：小众但属于输入同步的一部分

### B. VPet 有、咱们没有的
1. **海量动画矩阵**：32 类型 × 4 状态 × 3 类型动画组合；咱们只有少数几个表情
2. **互动玩法**：摸头、提起拖拽、爬墙、投喂（点宠物有反应）；咱们只有右键菜单
3. **创意工坊/用户自制内容分享**：玩家上传下载动画、物品、主题、插件；咱们没有分享渠道
4. **代码插件 SDK**：新功能以插件形式加载（闹钟/记事板/L2D 渲染方案），不用改主程序；咱们的"编辑器"只改配置，不能加新功能
5. **MOD 制作器**（帧图生成工具）：咱们只有 make_skin.py 单图抠图
6. **主题系统抽象**（basestyle/Theme）：咱们皮肤=一张图，没有主题层
7. **工作时钟**：宠物可以"去上班"，咱们没有宠物工作玩法
8. **AI 对话**（ChatGPT 设置窗口）：咱们没有聊天能力
9. **开发者控制台 + 反馈中心**（软件内上报）：咱们只有命令行自检
10. **可嵌入核心**（NuGet 打包，任何 WPF 程序可内嵌）：咱们 core/ 没有独立打包发布
11. **动画版权声明规范**：咱们没做素材版权合规检查

### C. clawd-on-desk 有、咱们没有的（价值最大）
1. **事件→状态→动画 三层映射表**（docs/guides/state-mapping.md）：把"发生什么→宠物处于什么状态→播哪段动画"做成标准表格；咱们是情绪数值→表情，没有正式状态机
2. **主题系统 theme.json + 脚手架脚本 + 校验脚本 + zip 导入**（可导入 Codex Pet 动画包）：咱们换皮肤=换一张图，没有"多状态资源包"概念
3. **权限气泡**：AI 请求权限时宠物弹出气泡让你批/拒；咱们只有自动跳转拦截页/强制关闭
4. **点击穿透**：透明区域点击穿透到下层窗口，只有宠物身体可交互；咱们的窗口大概率整块可点
5. **位置记忆**：跨重启记住宠物位置（含迷你模式位置）；咱们没保存位置
6. **单实例锁**：防止开两个桌宠；咱们没有
7. **开机自启**：咱们没有
8. **免打扰 DND 模式**：一键让宠物闭嘴（事件全部静音）；咱们只有番茄钟休息
9. **音效提示**（完成/请求权限时的短音效，可开关、免打扰自动静音）：咱们全程无声
10. **系统托盘**：咱们没有
11. **自动更新**（检测 GitHub Releases，Windows 退出时 NSIS 安装更新）：咱们没有
12. **多显示器适配**（比例缩放、竖屏增强）：咱们没有
13. **迷你模式**：宠物缩成迷你形态，咱们没有
14. **多语言 i18n**（6 种）：咱们纯中文
15. **持续眼睛追踪待机 + 随机待机动作**（光标跟随、阅读/巡逻动画）：咱们只有"鼠标靠近才看你"
16. **完成庆祝动画**（任务完成→Happy）：咱们结束会话只弹总结
17. **错误状态动画**：失败→难过表情，咱们没有错误反馈动画
18. **同状态分级动画资产**（1 个子代理 vs 2+ 子代理用不同动画）：对应咱们"越来越生气"可以用分级动画资产表达
19. **主题能力徽章**（Settings 里标注该主题支持 Tracked idle/Static/Mini 等）：细节 UX，咱们没有
20. **远程 SSH / 手机 PWA 伴侣**（跨设备批准/通知）：咱们没有

### D. RunCat365 有、咱们没有的
1. **系统指标→动画驱动**：CPU 占用率决定猫的奔跑速度——一种"用实时指标驱动持续动画"的玩法，咱们没有
2. **自定义跑步动画**（换 sprite）：咱们有皮肤但没这种"单指标动画"形式
3. **内置跑酷小游戏**：休息/奖励时可玩的小游戏，咱们没有
4. **微软商店分发渠道**：咱们计划浏览器商店，桌面端还没定分发渠道
5. **8 种语言**：咱们纯中文
6. **"无侵入"设计哲学**：不挡桌面、零学习成本——可借鉴做成咱们的"低调/迷你模式"
