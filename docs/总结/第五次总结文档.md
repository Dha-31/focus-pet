## 一、本次目标

v4.0.1 互动玩法：摸头/投喂/打工时钟 + 每日打卡 + 内置小游戏 + 空间场景切换（二维小世界第一步）。
约束：纯本地、零外部依赖；遵守自定义图像适配原则；集中配置 + 帮助中心数据驱动。
借鉴：VPet（工作时钟/投喂机制）、RunCat365（桌面小猫动起来的感觉）。

## 二、已完成内容

### 1. 摸头（单击互动）
- 单击桌宠本体 = 摸头（自动区分拖动：按下→释放位移 <6px 视为单击）
- 好感 +1（3 秒冷却防连点），宠物开心回应（气泡 + 短暂庆祝特效）

### 2. 投喂
- 右键 →「投喂…」→ 选择食物（小鱼干 10 币 +6 好感 / 牛奶 15 币 +10 / 蛋糕 25 币 +18）
- 花专注币换好感；价格/加成从集中配置 feed.items 读取

### 3. 打工（工作时钟）
- 右键 →「打工…」→ 选时长（30/60/120 分钟，可配）
- 开始后头顶显示 💼 + 剩余时间倒计时；时间到自动结算工资（汇率×时长，等级越高加成越多）
- 中途取消无奖励；持久化 data/work.json（重启不丢、继续倒计时）

### 4. 每日打卡
- 右键 →「每日打卡…」/ 启动时未打卡提醒；每天限一次
- 奖励 = 基础 10 币 + 连续签到加成（连续第 N 天 +N×2 币）；断签重置
- 持久化 data/checkin.json

### 5. 空间场景切换
- 我的空间左上角场景下拉框：温馨小屋 / 星空书房 / 海边 / 森林
- 不同配色 + 场景装饰（月亮星星、海浪、树木、挂画），家具照常摆放
- 持久化 data/space.json

### 配套
- 集中配置新增：checkin.base_reward / streak_bonus、work.rate_per_min / options、
  feed.items、space.scenes（编辑器自动出输入框）
- 帮助中心更新到 v4.0.1：新增 6 条功能说明（摸头/投喂/打工/打卡/小游戏/场景切换）
- README 功能清单与升级路线更新
